# FuuZhang homepage lettering

Google Sans Medium (weight 500), served by Google Fonts as a WOFF2 subset
containing the characters in `FuuZhang`. This local font is used only for the
homepage wordmark; no runtime request to Google Fonts is required.

Downloaded 2026-10-24 from:

- Specimen request: https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap&text=FuuZhang
- Typeface project: https://github.com/googlefonts/googlesans
- Design background: https://design.google/library/google-sans-flex-font

The font is redistributed under the SIL Open Font License 1.1 in `OFL.txt`.
This is a FuuZhang wordmark, not a Google logo asset.
